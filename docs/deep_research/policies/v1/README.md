# DeepResearch Policies v1 Schemas

These deterministic JSON Schemas describe B03 policy contracts and policy events. They are generated with `write_policy_schemas()` and compared byte-for-byte in tests. They do not define a real provider transport or production artifact format.

Files: `budget_spec.schema.json`, `budget_ledger.schema.json`, `policy_event.schema.json`, `operation_record.schema.json`, `operation_journal.schema.json`, `retry_policy.schema.json`, `replan_policy.schema.json`, and `replan_decision.schema.json`.
