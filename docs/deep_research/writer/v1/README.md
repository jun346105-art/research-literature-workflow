# Single Writer and Report Validator schemas v1

Canonical UTF-8/LF exports generated by `render_writer_schemas()`:

- `writer_content_draft.schema.json`, `report_section_draft.schema.json`, `claim_proposal.schema.json`, and `citation_proposal.schema.json` describe untrusted Writer content. The model does not own task/brief/plan/run/schema/report/claim/citation identity; formal `ReportDraft` is finalized by the program.
- `validated_report.schema.json`, `report_validation_issue.schema.json`, and `report_validation_result.schema.json` describe program-owned output and deterministic validation facts.

The export is byte-stability tested. `ReportDraft` ignores harmless extra metadata but rejects program-controlled identity/Evidence fields; durable result schemas forbid extras.
