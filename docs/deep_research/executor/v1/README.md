# B05 Executor Schemas v1

These canonical UTF-8/LF JSON Schemas are generated by `render_executor_schemas()`:

- `local_search_request.schema.json`
- `read_passage_request.schema.json`
- `local_passage.schema.json`
- `evidence_graph.schema.json`
- `local_executor_result.schema.json`

They describe offline contracts only and do not authorize providers, Web, writes or formal output artifacts.
