# Runtime Schema v2

This directory contains byte-stable JSON Schema exports for the B03R unified runtime stream and coordinated checkpoint.

- `runtime_event_envelope.schema.json`: one ordered event in the authoritative runtime stream.
- `coordinated_checkpoint.schema.json`: stream head plus atomically verified run state, ledger, and journal projections.

Schemas are generated by `litflow.deep_research.schema_export.write_runtime_v2_schemas()`. Hashes and replay use the single `canonical_json_bytes()` implementation; schema files are documentation/contracts, not permission to connect a real provider.
